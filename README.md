Disciplinary Differences in the Empirical Conceptualization and Theoretical Explanation of Gender Differences in STEM Pathways:
Contrasting Sociological and Psychological Concepts in the Context of Germany
================
This repository contains the supplementary material for the framework paper of the thesis "[Disciplinary Differences in the Empirical Conceptualization and Theoretical Explanation of Gender Differences in STEM Pathways:
Contrasting Sociological and Psychological Concepts in the Context of Germany
](https://github.com/ralfminor/disciplinary_differences_stem )". 

This repository contains a single file named "2025_09_27_Supplements_Disc_Diff_Minor". It includes documentation of the search process for the semi-systematic literature review of the associated thesis, as well as subsequent coding based on the literature sample.
